# 개설 과목 자동 업데이트 — 운영 안내

`courses.html`의 개설 과목 데이터는 학과 홈페이지 게시물의 엑셀에서 자동으로 만들어집니다.
관리자가 할 일은 **PR이 오면 확인하고 머지하기**, **실패 Issue가 오면 표를 보고 대응하기** 두 가지입니다.

## 어떻게 돌아가나

```
매일 09:00 (GitHub Actions)
  │
  ├─ 학과 게시물(uid=1613) 제목의 날짜와 첨부 엑셀의 해시를 확인
  │     바뀐 게 없으면 → 종료 (아무 일도 없음)
  │
  ├─ 바뀌었으면 엑셀을 내려받아 js/courses-data.js 를 다시 만들고
  │     ├─ 잘 읽혔으면 → PR 생성 (리뷰어: CODEOWNERS)  ──▶ 사람이 머지 ──▶ Vercel이 배포
  │     └─ 구조를 못 읽었으면 → Issue 생성 (담당자: CODEOWNERS), 사이트는 기존 데이터 유지
```

- 원천: https://ie.snu.ac.kr/archive/?mod=document&uid=1613 (제목 예: `향후 2년 개설 예정 교과목 목록(2026.07.29기준 업데이트)`)
- 결과: `js/courses-data.js` — 자동 생성 파일이라 직접 고치지 않습니다. 화면은 이 파일 하나만 읽습니다.
- 화면은 데이터 중 **현재 학기와 그 이전 3학기부터**만 보여줍니다(`js/script.js`의 `PAST_TERMS_SHOWN`). 학기가 바뀌면 지난 학기 버튼은 엑셀 업데이트 없이도 자동으로 빠집니다.

## PR이 왔을 때 (`개설 과목 데이터 업데이트 (YYYY-MM-DD)`)

1. PR 본문의 표에서 자료 날짜·과목 수가 상식적인지 봅니다.
2. **"확인할 점"**이 있으면 하나씩 확인합니다.
   - `모르는 구분 값 "X"` → 엑셀에 새 구분이 생긴 것입니다. 맞는 값이면 `data/course-schema.json`의 `types.known`에 추가하고, 아래 "수동 실행"으로 다시 만듭니다. 오타면 `types.aliases`에 `"X": "전선"`처럼 교정 규칙을 넣습니다.
   - `모르는 학년/영역 값` → 같은 방식으로 `categories.known`에 추가합니다(화면에는 이미 그대로 표시됩니다).
   - `사라진 과목` → 과목명이 바뀐 경우가 많습니다. 엑셀을 열어 확인만 하면 됩니다.
   - `과목 수가 N% 바뀜` → 엑셀 구조가 바뀌어 일부 행을 못 읽은 건 아닌지 PR의 Preview에서 목록을 훑어봅니다.
3. PR의 Vercel bot 댓글에 있는 **Preview** 링크를 열어 `courses.html`과 홈 메타("N개 과목 · YYYY-N학기까지", footer 날짜)를 봅니다.
4. 이상 없으면 **Merge**. 머지되면 몇 분 안에 사이트에 반영됩니다.

같은 날짜의 PR이 이미 열려 있으면 새 PR을 만들지 않고 그 PR의 브랜치를 갱신하고 댓글을 답니다.

## 실패 Issue가 왔을 때 (`개설 과목 자동 업데이트 실패 (YYYY-MM-DD)`)

사이트는 기존 데이터를 그대로 보여주고 있으니 급하지 않습니다. Issue 본문의 "대응" 표를 따릅니다.

| 원인 | 대응 |
|---|---|
| 헤더(교과목명/구분/학기)를 못 찾음 | 엑셀을 열어 헤더 이름을 확인하고 `data/course-schema.json`의 `headers`에 추가 |
| 제목에서 날짜를 못 찾음 | 제목 형식이 바뀐 것. 개발자에게 `scripts/update-courses/lib/post.js`의 `DATE_PATTERNS` 수정을 요청 |
| xlsx 첨부가 없거나 2개 이상 | 게시물을 직접 확인. 새 게시물로 옮겨졌으면 `sourcePostUid`/`sourcePostUrl`을 바꿈 |
| 게시물 응답 오류(404/500) | 게시물이 삭제·이동됐는지 확인 후 uid 변경 |
| 첨부가 xlsx가 아님 | 학과 사이트가 로그인을 요구하기 시작했을 수 있음. 개발자 확인 |

고친 뒤 "수동 실행"으로 바로 다시 돌릴 수 있습니다. 해결되면 Issue를 닫습니다. 같은 이유로 매일 실패하면 새 Issue 대신 기존 Issue에 댓글이 달립니다.

### 급할 때: 엑셀을 직접 넣어 만들기

```bash
cd scripts/update-courses
npm ci
node bin/run.js --file ~/Downloads/받은파일.xlsx --date 2027-01-15 --force
```

`js/courses-data.js`가 갱신됩니다. 브랜치를 만들어 커밋하고 PR을 올리면 됩니다.

## 수동 실행

GitHub 레포 → **Actions** 탭 → 왼쪽 **Update courses** → **Run workflow**.
"바뀌지 않았어도 다시 만든다"를 켜면 게시물이 그대로여도 데이터를 다시 생성합니다(스키마 파일을 고친 뒤 쓰세요).

## 설정 파일: `data/course-schema.json`

| 키 | 뜻 |
|---|---|
| `sourcePostUid`, `sourcePostUrl` | 읽어올 게시물 |
| `headers.name`, `headers.type` | 엑셀에서 교과목명·구분 열을 찾을 때 쓰는 헤더 이름 후보(공백 무시) |
| `categories.known` | 학년/영역 열에 올 수 있는 값. 없는 값은 경고만 |
| `types.known` | 구분 열에 올 수 있는 값. 없는 값은 빈 값으로 바꾸고 경고 |
| `types.aliases` | 알려진 오타 교정 (`"O": ""`는 실제로 있었던 오타) |
| `validation.courseCountChangeWarnRatio` | 과목 수 변화가 이 비율을 넘으면 경고 (0.2 = 20%) |

학기 열은 `YYYY학년도 N학기` 패턴으로 자동 인식하므로 설정이 필요 없습니다.

## 관리자 교체 체크리스트

1. 신임 관리자를 레포 **Settings → Collaborators**에 Write 권한으로 초대합니다.
2. `.github/CODEOWNERS`의 계정을 신임 관리자로 바꿉니다. (팀으로 운영하면 `@조직/팀` 한 줄로 바꾸고 이후엔 팀 멤버만 관리)
3. 신임 관리자가 레포를 **Watch**(최소 Participating)하도록 안내합니다. PR 리뷰 요청과 Issue 배정은 GitHub 계정 이메일로 갑니다.
4. 이 문서 링크를 넘깁니다.

## 최초 1회 설정 (이미 돼 있어야 하는 것)

- 레포 **Settings → Actions → General → Workflow permissions**: "Read and write permissions" + **"Allow GitHub Actions to create and approve pull requests"** 체크. 이게 꺼져 있으면 PR 생성 단계가 실패합니다.
- Vercel 프로젝트가 이 레포에 연결돼 있고 PR Preview가 켜져 있어야 합니다(기본값).
- 레포에 60일 동안 커밋이 없으면 GitHub이 스케줄을 자동으로 끄는데, 워크플로가 매 실행마다 스스로 다시 켜서 막습니다. 그래도 Actions 탭에 "This scheduled workflow is disabled" 배너가 보이면 **Enable workflow**를 누르세요.

## 코드 구조 (개발자용)

```
data/course-schema.json          관리자가 고치는 설정
js/courses-data.js               자동 생성 데이터 (window.COURSE_SOURCE)
js/script.js                     normalizeCourses() 한 곳만 원천 형식을 알고, 화면은 getVisibleCourses()만 읽음
                                 courses-data.js가 없거나 깨지면 내장 upcomingCourses로 폴백
scripts/update-courses/
  bin/run.js                     실행기 (게시물 확인 → 다운로드 → 파싱 → 파일 생성 → out/ 보고서)
  lib/post.js                    게시물 HTML에서 제목 날짜·첨부 URL 읽기, 다운로드
  lib/xlsx.js                    xlsx → 행 배열 (exceljs 의존은 여기만)
  lib/parse-courses.js           행 배열 → 내부 형식. 구조 오류는 errors, 값 오류는 warnings
  lib/data-file.js               courses-data.js 쓰기/읽기
  lib/report.js                  PR·Issue 본문
  test/                          실제 엑셀(2026-07-29)로 64개 과목이 그대로 나오는지 확인하는 회귀 테스트 등
.github/workflows/update-courses.yml
.github/CODEOWNERS               알림 대상
```

테스트: `cd scripts/update-courses && npm ci && npm test`
